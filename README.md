# Fahmid Nursery & Primary School — Advert Video

A 30-second vertical (1080×1920) advert built with Remotion — the video
is written as React code, and GitHub Actions renders it to an MP4 you
can download. No video editing software required.

## How to get your video

1. Push everything to this repo (done once all files + logo.png are added).
2. Check the **Actions** tab — a render run starts automatically.
3. When it finishes (green checkmark), open the run and download the
   **fahmid-advert-video** artifact — that's your MP4.
